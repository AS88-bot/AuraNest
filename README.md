# AuraNest - Your Compassionate Companion

AuraNest is a supportive web application designed to assist individuals with dementia or memory challenges, as well as their caregivers. It combines daily planning, communication, and innovative AI-powered features to create a reassuring and organized environment.

## ✨ Features

- **Daily Planner**: A clear, time-based view of the day's schedule, including medications, meals, and appointments.
- **Verbal Reminders**: Create audible reminders in multiple languages and voices to provide gentle, spoken cues for important tasks.
- **Voice-Powered Assistant**: An intuitive voice assistant that can make calls, navigate the app, and set reminders using natural language.
- **AI Chatbot**: A friendly conversational AI, "Aura," available to provide companionship and answer questions.
- **Memory Journal**: Record thoughts and memories using voice-to-text, and generate a simple "Today in My Life" summary with the help of AI.
- **Mood Tracker**: Log daily emotions with simple emoji-based input and receive a short, supportive message from an empathetic AI.
- **Contact Management**: Easy access to important contacts with large photos and simple "call" buttons.
- **Caregiver Dashboard**: A dedicated view for caregivers to monitor a user's location and status, including SOS alerts.
- **Emergency SOS**: A prominent SOS button that can send the user's current location to emergency contacts.
- **Multi-Language Support**: The UI and AI interactions are available in English, Spanish, French, German, Hindi, and Italian.
- **Firebase Integration**: Built on a solid foundation with Firebase Authentication for user management and Firestore for a real-time database.

## 🚀 Getting Started

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

### Prerequisites

- Node.js (version 20 or later)
- npm or yarn

### Installation & Running Locally

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Run the development server:**
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.

The app will connect to a provisioned Firebase backend for authentication and database services.
