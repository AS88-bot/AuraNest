# **App Name**: AuraNest

## Core Features:

- Visual Daily Planner: Display a daily schedule using color-coded blocks and icons for appointments, medication, meals, and activities, including voice prompts and reminders.
- Medication and Task Reminders: Provide timed alerts with images of medications or tasks, allowing confirmation of completion via tap or voice.
- Photo-Based Contact Book: Display contacts with faces instead of names, including one-tap call or video buttons for caregivers and family.
- Memory Journal/Timeline: Allow users to record thoughts, photos, or voice notes. Include 'Today in My Life' summaries. This tool will generate summaries based on daily entries.
- Emergency SOS Button: A disguised SOS button that sends location and alert to caregivers.
- Location Tracking and Safe Zones: Allow caregivers to set geofences and receive alerts if the user wanders outside these zones.
- Guided Navigation: Provide step-by-step directions with voice and visual cues, including a 'Take Me Home' button.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to evoke a sense of calm and security.
- Background color: Very light desaturated lavender (#F5F5FF) for a gentle backdrop.
- Accent color: Muted violet (#D8BFD8) for highlighting important information without causing overstimulation.
- Body and headline font: 'PT Sans' a humanist sans-serif that is modern but has some warmth.
- Use large, clear, and universally recognizable icons that represent common actions and items.
- Maintain a clean and straightforward layout with large buttons and minimal text to reduce cognitive load.
- Employ subtle animations and transitions to provide visual cues without being distracting or overwhelming.
